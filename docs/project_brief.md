# Project Brief: E-Commerce Sales and Customer Analytics Dashboard

## 1. Business Context
Olist is a Brazilian e-commerce marketplace that connects small sellers
to customers across the country. Like a business team asking an analyst for reports, this business needs answers from its data: which products and sellers perform best, which regions sell the most, and how delivery time affects reviews. I analyze the data with SQL and Python and present the results in Power BI.

## 2. Objective
Analyze order, delivery, payment, and review data to understand what
drives revenue and customer satisfaction, and present the findings in
an interactive Power BI dashboard.

## 3. Business Questions
1. How have revenue and order volume changed over time?
2. Which product categories and states generate the most revenue?
3. How does delivery delay affect customer review scores?
4. What percentage of customers are repeat buyers?
5. Which sellers perform best and worst?
6. Which payment methods are used most?

## 4. Dataset
- Source: Brazilian E-Commerce Public Dataset by Olist (Kaggle)
- 9 CSV files: orders, order items, payments, reviews, customers,
  sellers, products, geolocation, product category translation
- Period: September 2016 to October 2018
- Volume: about 99,000 orders, 112,000 order items, and 9 tables

## 5. Tools
MySQL, Python (Pandas, Matplotlib), Power BI, Excel

## 6. Deliverables
- Cleaned dataset
- SQL queries answering each business question
- Python notebook with EDA and visualizations
- Power BI dashboard
- Summary of insights and recommendations

## 7. Approach
1. Load and understand the data
2. Check data quality and clean
3. Analyze with SQL
4. Explore and visualize with Python
5. Build the Power BI dashboard
6. Document insights and recommendations
